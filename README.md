# UpRice 🌾

UpRice is an offline-first climate resilience platform designed for smallholder rice farmers. It combines field data from SmartPani, satellite insights, and community verification to help farmers make informed irrigation decisions and improve climate resilience.

## Problem

Rice farmers often face delayed or inaccessible field information, making it difficult to respond to droughts, flooding, and changing weather conditions.

## Solution

UpRice brings together:

* SmartPani water-level monitoring
* Satellite-supported field insights
* Offline-first mobile experience
* Community field verification
* Farmer-friendly dashboards

## Features

* Water-level monitoring with SmartPani
* Field status dashboard
* Community verification system
* Offline-first experience
* Farmer profile and field management

## Getting Started

Clone the repository.

```bash
git clone https://github.com/chrystalaa/UpRice.git
cd UpRice
```

Install dependencies.

```bash
npm install
```

Run the development server.

```bash
npx expo start
```
